# Security policy

## Project status

zAccounting is in early development and is not ready for production accounting data. Do not deploy it for real financial records or rely on it for financial, tax, regulatory or security decisions.

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue. If this repository is hosted on GitHub and private vulnerability reporting is enabled, use the repository's **Report a vulnerability** feature. Otherwise, contact the repository maintainers through a private channel.

Do not include passwords, access tokens, bank credentials, customer information or real financial records in a report. Provide a minimal reproduction with synthetic data where possible.

There is currently no published response-time commitment. We will update this file when a supported release and formal response process are established.
